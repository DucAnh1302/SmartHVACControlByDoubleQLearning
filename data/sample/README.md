# Sample Data

This directory contains small datasets or representative samples used for development, debugging, and demonstrations.

Thư mục này chứa các tập dữ liệu nhỏ hoặc các mẫu đại diện được sử dụng cho mục đích phát triển, gỡ lỗi và trình diễn.

Sample data should be small enough to be safely used during development without loading the complete CU-BEMS dataset.

Dữ liệu mẫu cần có kích thước đủ nhỏ để có thể sử dụng an toàn trong quá trình phát triển mà không cần phải tải toàn bộ tập dữ liệu CU-BEMS.
