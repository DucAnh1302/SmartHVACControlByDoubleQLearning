# Processed Data

This directory contains datasets generated after preprocessing and feature engineering.
Thư mục này chứa các tập dữ liệu được tạo ra sau quá trình tiền xử lý và kỹ thuật đặc trưng (feature engineering).

## Expected Operations

Depending on the final methodology, preprocessing may include:

- Missing value handling
- Timestamp processing
- Data filtering
- Resampling
- Normalization
- Feature engineering
- State representation preparation

Tùy thuộc vào phương pháp luận cuối cùng, quá trình tiền xử lý có thể bao gồm:

- Xử lý giá trị thiếu
- Xử lý dấu thời gian (timestamp)
- Lọc dữ liệu
- Lấy mẫu lại (resampling)
- Chuẩn hóa
- Kỹ thuật đặc trưng
- Chuẩn bị biểu diễn trạng thái

Processed datasets should always be reproducible from the raw data and preprocessing code.
